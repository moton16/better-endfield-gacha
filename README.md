# Better Endfield Gacha

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

> 《明日方舟：终末地》本地抽卡记录管理与分析工具。重点解决 **B 服** 拿不到抽卡链接的痛点，同时兼容官服与国际服。数据全程只保存在你的本机。

> [!NOTE]
> 当前处于 **`0.1.0-rc.1`** 发布候选阶段：桌面轻壳应用（安装版 / 桌面便携包）、命令行便携包、内置静态游戏图包与自选头像、浅色工业风本地界面、双路线同步（含森空岛一键扫码与缓存凭据复用）、保底分析与导入导出已就绪；将在补充干净 Windows 实机全链路安装验证后切出正式版 `0.1.0`。

## 核心特性

- **双路线同步，B 服官服都能用**：
  - **路线 A（读取游戏缓存 · Windows PC）**：无需登录鹰角通行证、不输入任何账号密码、不修改游戏、不抓包、不装证书。在游戏里打开一次「寻访记录」即可读取凭据并拉取全部记录，游戏运行中也可直接同步；有效凭据会在本机加密缓存复用，无需每次重开游戏内记录页，遇 `40100` 过期时再自动重扫或按提示刷新。
  - **路线 B（鹰角通行证 · 跨平台 / 不开游戏）**：无需启动游戏客户端即可同步名下全部可用角色，国服支持 **森空岛 App 一键扫码登录**（网页端本地二维码与命令行终端二维码，免手动粘贴口令），也支持粘贴通行证口令（兼容国际服；B 服玩家须先在鹰角官网绑定 B 服角色；不支持直接输入 B 站账号密码）。
- **全卡池拉取与保底分析**：覆盖角色 5 类寻访池与武器各类申领池，自动识别小/大保底进度、歪/UP 情况、同周期五星陪跑、武器十连视图与欧非徽章，自动排除「寻访情报书」等非抽卡赠品；如遇缺失 UP 信息的新旧卡池，还可在 `data/` 目录放置 `up-map.override.json` 本地补充。
- **突破 90 天限制**：官方仅保留近期记录，本工具把记录保存在本地，每次增量补齐新抽卡，历史数据长久不丢失。
- **官服 / B 服 / 多角色互不串号**：按渠道与角色独立分档存储，支持本地多账号切换查看与按账号自选头像。
- **独立桌面窗口 + 本地网页 + 导入导出**：支持 Tauri v2 桌面轻壳与本地网页界面，支持标准备份导出、Excel 表格导出、离愁轩记录救援导入与写入前自动快照备份。
- **隐私默认脱敏**：界面、终端与日志默认隐藏账号编号、昵称与自定义头像，绝不上传任何个人数据。

## 快速上手（5 分钟跑通）

### 方式一：Windows 桌面版（推荐，独立窗口）

1. 选择以下任一发行包下载（无需提前安装 Node.js）：
   - **安装版**：`better-endfield-gacha-<版本>-win-x64-setup.exe`（支持当前用户安装；联网时可自动引导安装 WebView2 运行时）。
   - **桌面便携包**：`better-endfield-gacha-<版本>-win-x64-desktop.zip`——**请先完整解压到普通可写文件夹**（例如 `E:\Games\BetterEndfieldGacha\`），切勿直接在压缩包预览窗口或 `%TEMP%` 系统临时目录中运行，也请避开只读或受系统保护目录。
2. 运行 **Better Endfield Gacha**（便携包双击 `better-endfield-gacha.exe`）：
   - 自动检查目录可写性与 WebView2 运行环境，并在单实例独立窗口中打开本地分析界面。
   - 在界面右上角点击 **「同步」**，选择 **「游戏缓存（零绑定）」**（先在游戏里打开一次「寻访详情 → 寻访记录」）或 **「鹰角通行证」**（点击 **「扫码登录」** 后用森空岛 App 扫码），即可一键拉取并查看保底统计。

### 方式二：Windows 命令行便携版（无需提前安装 Node）

1. 下载便携压缩包 `better-endfield-gacha-<版本>-win-x64.zip`。
2. **解压到普通可写文件夹**（例如 `E:\Games\BetterEndfieldGacha\`）。
3. 进入解压目录，**双击 `beg.cmd`** 自动启动本地服务并打开图形界面窗口；或在终端运行命令行：
   - `beg.cmd version`、`beg.cmd scan`、`beg.cmd sync`
   - 扫码登录并加密保存：`beg.cmd login --qr --save`，随后 `beg.cmd sync --passport`（或一次性 `beg.cmd sync --passport --qr`）
   - 导出备份：`beg.cmd export --out backup.json`

### 方式三：从源码运行（需要 Node.js 22.13 及以上，推荐 24）

```pwsh
pnpm install
pnpm build
pnpm cli serve
```

常用命令行参数：`--channel 2` 仅筛选 B 服（`1` 为官服）、`--data-dir <目录>` 指定数据目录、`--show-ids` 在终端明文显示账号信息。

## B 服两种路线怎么选？

| 使用场景 | 推荐路线 | 简要说明 |
|---|---|---|
| 在 Windows 电脑上玩终末地 | **路线 A（游戏缓存）** | 零绑定最省心，首次提取后本机加密复用；若提示 `40100` 过期，在游戏内重新打开一次「寻访记录」或直接切换扫码即可 |
| 手机端游玩 / 不方便开游戏 | **路线 B（鹰角通行证）** | 须先在 [user.hypergryph.com](https://user.hypergryph.com/) 绑定 B 服角色；国服直接点击「扫码登录」或执行 `--qr` 扫码即可同步 |

> 详细操作步骤、扫码登录、头像与卡池 UP 覆盖、离愁轩导入步骤及常见报错排查，请查阅 **[快速上手与排障指南](QUICKSTART.md)**。

## 数据位置、备份与隐私安全

- **数据保存在哪里**：桌面便携版与命令行便携版默认均保存在程序同级的 `data` 文件夹内（源码运行默认在当前目录的 `data` 文件夹，均可通过 `--data-dir` 或环境变量 `BEG_DATA_DIR` 修改）。升级版本时只需**保留原有的 `data` 文件夹**，替换其余程序文件即可无损继承记录；若需补充自定义卡池 UP 映射，可在 `data` 文件夹放置 `up-map.override.json`。
- **如何备份与清除**：随时在界面「导入/导出」中导出完整备份或创建手动快照；导入写入前也会自动先备份一次。如需彻底清理数据，退出程序后删除 `data` 文件夹即可。
- **本地服务与桌面安全边界**：桌面版仅允许窗口在本地回环地址内跳转，并在临时目录或只读目录启动时主动弹窗拦截，防止记录丢失；网页界面仅在本机回环地址启动并附带本次运行随机生成的访问密钥与本机源校验，**不会向局域网或外网开放**；请**不要**将地址栏里带有 `#k=...` 的完整地址或你的抽卡链接截图/分享给他人。
- **隐私遮罩与头像**：界面默认开启隐私遮罩，此时会隐藏昵称、账号编号并将自定义头像遮罩为「终」字占位；点击昵称旁的眼睛图标可切换显示明文，点击左上角头像可选择预设头像、干员头像或上传本地图片裁剪作为头像。
- **通行证与缓存凭据提示**：路线 B 勾选加密保存的通行证会话与路线 A 复用的查询凭据，均通过当前 Windows 账户的系统保护能力加密存储于本地（同电脑、同 Windows 登录用户下的其他程序原则上仍可请求解密），请勿在公用电脑使用。不再使用时请点击「清除全部」（或运行 `beg.cmd logout`），并前往 [user.hypergryph.com](https://user.hypergryph.com/) 手动退出对应设备会话。
