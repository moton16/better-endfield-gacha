# Better Endfield Gacha

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

> 《明日方舟：终末地》本地抽卡记录管理与分析工具。重点解决 **B 服** 拿不到抽卡链接的痛点，同时兼容官服与国际服。数据全程只保存在你的本机。

> [!NOTE]
> 当前处于 **`0.1.0-dev`** 预览阶段：免安装便携包、本地网页界面、双路线同步、保底分析与导入导出已就绪；待完成实机全链路验证后将切出首个正式版 `0.1.0`。

## 核心特性

- **双路线同步，B 服官服都能用**：
  - **路线 A（读取游戏缓存 · Windows PC）**：无需登录鹰角通行证、不输入任何账号密码、不修改游戏、不抓包、不装证书。在游戏里打开一次「寻访记录」即可读取凭据并拉取全部记录，游戏运行中也可直接同步。
  - **路线 B（鹰角通行证 · 跨平台 / 不开游戏）**：无需启动游戏客户端即可同步名下全部可用角色，适合手机端或跨设备玩家（B 服玩家须先在鹰角官网绑定 B 服角色；不支持直接输入 B 站账号密码）。
- **全卡池拉取与保底分析**：覆盖角色 5 类寻访池与武器各类申领池，自动识别小/大保底进度、歪/UP 情况、欧非徽章与卡池总览，自动排除「寻访情报书」等非抽卡赠品。
- **突破 90 天限制**：官方仅保留近期记录，本工具把记录保存在本地，每次增量补齐新抽卡，历史数据长久不丢失。
- **官服 / B 服 / 多角色互不串号**：按渠道与角色独立分档存储，支持本地多账号切换查看。
- **本地图形界面 + 导入导出**：自带本地网页界面，支持标准备份导出、Excel 表格导出、离愁轩记录救援导入与写入前自动快照备份。
- **隐私默认脱敏**：界面、终端与日志默认隐藏账号编号与昵称，绝不上传任何个人数据。

## 快速上手（5 分钟跑通）

### 方式一：Windows 便携版（推荐，无需提前安装 Node）

1. 下载便携压缩包 `better-endfield-gacha-<版本>-win-x64.zip`。
2. **解压到普通文件夹**（建议放在非系统盘，例如 `E:\Games\BetterEndfieldGacha\`）。
3. 进入解压目录，**双击 `beg.cmd`**：
   - 自动启动本地服务并打开图形界面窗口。
   - 在界面右上角点击 **「同步」**，按你的游戏方式选择 **「从游戏缓存同步」**（先在游戏里打开一次「寻访详情 → 寻访记录」）或 **「鹰角通行证」**，即可一键拉取并查看保底统计。
4. 如需使用命令行，可在解压目录终端运行：`beg.cmd version`、`beg.cmd scan`、`beg.cmd sync`、`beg.cmd export --out backup.json`。

### 方式二：从源码运行（需要 Node.js 22.13 及以上，推荐 24）

```pwsh
pnpm install
pnpm build
pnpm cli serve
```

常用命令行参数：`--channel 2` 仅筛选 B 服（`1` 为官服）、`--data-dir <目录>` 指定数据目录、`--show-ids` 在终端明文显示账号信息。

## B 服两种路线怎么选？

| 使用场景 | 推荐路线 | 简要说明 |
|---|---|---|
| 在 Windows 电脑上玩终末地 | **路线 A（游戏缓存）** | 零绑定最省心；若提示凭据过期，在游戏内重新打开一次「寻访记录」即可 |
| 手机端游玩 / 不方便开游戏 | **路线 B（鹰角通行证）** | 须先在 [user.hypergryph.com](https://user.hypergryph.com/) 绑定 B 服角色，再粘贴通行证口令同步 |

> 详细图文步骤、命令行管道登录方式、离愁轩导入步骤及常见报错排查，请查阅 **[快速上手与排障指南](QUICKSTART.md)**。

## 数据位置、备份与隐私安全

- **数据保存在哪里**：便携版默认保存在软件目录同级的 `data` 文件夹内（源码运行默认在当前目录的 `data` 文件夹，均可通过 `--data-dir` 修改）。升级版本时只需**保留原有的 `data` 文件夹**，替换其余程序文件即可无损继承记录。
- **如何备份与清除**：随时在界面「数据管理」导出完整备份或创建手动快照；导入写入前也会自动先备份一次。如需彻底清理数据，退出程序后删除 `data` 文件夹即可。
- **本地服务安全边界**：网页界面仅在你的本机回环地址启动，并附带本次运行随机生成的访问密钥与本机源校验，**不会向局域网或外网开放**；请**不要**将地址栏里带有 `#k=...` 的完整地址或你的抽卡链接截图/分享给他人。
- **通行证会话提示**：若在路线 B 勾选加密保存通行证会话，凭据仅通过当前 Windows 账户的系统保护能力加密存储于本地（同电脑、同 Windows 登录用户下的其他程序原则上仍可请求解密），请勿在公用电脑使用。不再使用时请点击「清除已保存会话」（或运行 `beg.cmd logout`），并前往 [user.hypergryph.com](https://user.hypergryph.com/) 手动退出对应设备会话。
